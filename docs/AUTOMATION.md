# 🤖 Автоматизация дистрибуции «Контент-Завода»

Полное руководство: как превратить кнопку «Разослать» в автоматический постинг
по всем площадкам. PDF-версии инструкций — в [`docs/pdf/`](pdf/).

---

## Архитектура выходов

```
┌────────────────┐   POST JSON    ┌─────────────────────────┐
│  Контент-Завод │ ─────────────▶ │ Netlify Function        │ ──▶ Telegram Bot API ──▶ канал
│  (браузер)     │                │ /telegram-post          │
│                │   POST JSON    ├─────────────────────────┤
│                │ ─────────────▶ │ Вебхук n8n/Make/Zapier  │ ──▶ VK, Дзен, TG, почта…
└────────────────┘                └─────────────────────────┘
```

Два реальных выхода уже встроены; всё остальное строится сценарием в системе
автоматизации без единой строчки кода.

## Схема payload вебхука

Завод отправляет на ваш вебхук `POST` с `Content-Type: application/json`:

```json
{
  "source": "lure-content-factory",
  "version": 1,
  "title": "🪱 Силикон «Keitech Easy Shiner 4\"»",
  "text": "полный текст поста с CTA и UTM-ссылкой…",
  "meta": {
    "framework": "aida",
    "tone": "friendly",
    "length": "medium",
    "lureType": "soft",
    "lang": "ru",
    "chars": 556
  },
  "photoDataUrl": "data:image/jpeg;base64,…  (если включено «Прикладывать фото»)",
  "createdAt": "2026-07-05T12:00:00.000Z"
}
```

> Если вебхук не отдаёт CORS-заголовки, завод повторяет запрос в режиме
> `no-cors`: доставка происходит, но статус ответа прочитать нельзя —
> в журнале это помечается «без чтения ответа».

## Прямая интеграция Telegram

1. **Бот:** в Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` →
   получите токен вида `1234567890:AAE…`.
2. **Канал:** добавьте бота в канал → «Администраторы» → права «Публикация сообщений».
3. **Дашборд:** «Дистрибуция» → токен + ID канала (`@имя_канала` или числовой `-100…`).
4. Функция-прокси (`netlify/functions/telegram-post.mjs`) сама решает:
   - есть фото и текст ≤ 1024 символов → `sendPhoto` с подписью;
   - текст длиннее → `sendPhoto` + догоняющее `sendMessage`;
   - без фото → `sendMessage`.

**Лимиты Bot API:** ~30 сообщений/сек по разным чатам, ~20 сообщений/мин в один
канал. Для очередей ставьте паузу в сценарии автоматизации.

**Безопасность:** токен хранится в `localStorage` браузера и передаётся только
через вашу же функцию Netlify. Для продакшена рекомендуем перенести токен в
переменную окружения Netlify (`TG_BOT_TOKEN`) — см. дорожную карту.

## Сценарий n8n (рекомендуемый маршрут)

Подробная установка — PDF **«Установка автоматизации: n8n → Telegram»**.

Кратко: `Webhook (POST) → IF (meta.lang) → Telegram node / VK node → Sheets (лог)`.
Шаблон логики:

1. **Webhook** — триггер, метод POST, Respond immediately.
2. **Set** — вытащить `title`, `text`, `photoDataUrl`.
3. **Move Binary Data** (опция) — конвертировать base64 из `photoDataUrl` в бинарник.
4. **Telegram** — Send Photo (binary) + caption, либо Send Message.
5. Ветки на другие площадки — VK (HTTP Request к `wall.post`), Дзен, e-mail.

## Сценарий Make / Zapier / Albato

Подробно — PDF **«Автопостинг через Make и Zapier»**. Кратко:

- **Make:** Custom webhook → Router → Telegram Bot «Send a Photo» / VK / другие модули.
- **Zapier:** Webhooks by Zapier (Catch Hook) → Formatter → каналы.
- **Albato:** Вебхук-приёмник → связка «Телеграм-бот», «ВКонтакте» — интерфейс русскоязычный.

## Планирование публикаций (v0.3+)

Пока завод шлёт «сейчас». Отложенный постинг делается на стороне сценария:
в n8n — узел **Wait/Schedule**, в Make — Scheduling у сценария. В дорожной
карте — собственная очередь с датами прямо в дашборде.

## Диагностика

| Симптом | Причина / решение |
|---|---|
| Telegram: «Прокси ответил 404» | Открыт локальный dev-сервер — функция живёт только на деплое Netlify |
| Telegram: `chat not found` | Бот не добавлен админом в канал, либо ID указан без `@` / `-100` |
| Telegram: `bot token is invalid` | Токен скопирован не полностью |
| Вебхук: «отправлено (без чтения ответа)» | Нормально: приёмник без CORS; проверьте выполнение сценария на стороне сервиса |
| Вебхук: 4xx/5xx | Сценарий выключен или URL устарел — перевыпустите вебхук |
