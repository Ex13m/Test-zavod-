# 🤖 ИИ-агент завода: как это устроено и как включить

## Зачем

Три задачи, которые эвристика решает слабо, а нейросеть — хорошо:

| Задача | Эвристика (без ключа) | ИИ-агент (с ключом) |
|---|---|---|
| Тип товара по фото | по имени файла | **смотрит на фото**: тип из 14 категорий, бренд, торговое название |
| Стиль постов по скринам | пиксельные признаки | **читает тексты**: тон, реальные хэштеги, фирменные обороты, язык, CTA-манера |
| Профиль магазина по URL | по домену и TLD | **скачивает и читает сайт**: ниша, бренды, аудитория, теги |

Результаты ИИ напрямую питают генератор: реальные хэштеги магазина идут в посты,
фирменные обороты становятся крючками, распознанное название товара — в заголовок.

## Архитектура

```
Браузер ──POST──▶ /.netlify/functions/ai-agent ──▶ Claude / Gemini / OpenRouter
   ▲  фолбэк: нет ключа/сети → эвристика, завод работает всегда
```

- Функция: `netlify/functions/ai-agent.mjs`, задачи `product | style | shop`.
- Ключ живёт **только на сервере Netlify** — в браузер и в git не попадает.
- Фронт-клиент: `src/engine/agent.js`; статус агента виден в «Настройки → ИИ-агент».

## Провайдеры — платный и два бесплатных

Функция берёт первый провайдер, у которого задан ключ (в этом порядке):

| Приоритет | Провайдер | Env-ключ | Модель по умолчанию | Цена |
|---|---|---|---|---|
| 1 | Anthropic Claude | `ANTHROPIC_API_KEY` | `claude-opus-4-8` (минимум Opus 4.8; сменить: `AI_MODEL`) | платно, максимум качества |
| 2 | Google Gemini | `GEMINI_API_KEY` | `gemini-2.5-flash` (сменить: `GEMINI_MODEL`) | **бесплатный лимит** |
| 3 | OpenRouter | `OPENROUTER_API_KEY` | `google/gemini-2.0-flash-exp:free` (сменить: `OPENROUTER_MODEL`) | **бесплатные :free-модели** |

Все три умеют Vision (смотреть на фото) — все задачи агента работают на любом из них.

## Задачи агента

| task | Что делает | Веб-поиск |
|---|---|---|
| `product` | фото товара → `{ type, name, brand, fish, details }` — тип из 14 категорий, торговое название, целевая рыба с упаковки | — |
| `enrich` | название/бренд/тип → `{ about, usage, fish[], facts[], season }` — реальные факты о товаре для постов | Gemini: google_search grounding; Claude: web_search; OpenRouter: знания модели |
| `style` | скрины постов → профиль стиля (тон, хэштеги, обороты) | — |
| `shop` | URL магазина → профиль по живому HTML | — |
| `ping` | тестовый запрос — проверка, что ключ принят провайдером | — |

Результат `enrich` хранится на товаре (`lure.info`) и вплетается в посты:
факты серии → выгоды, применение → доказательство, рыба и сезон — из знаний о товаре.

## Как включить — способ 1: ключ прямо в интерфейсе (проще всего)

1. Возьмите любой ключ (см. таблицу выше): бесплатный Gemini `AIza…`, OpenRouter `sk-or-…` или платный Claude `sk-ant-…`.
2. На сайте завода: **Настройки → ИИ-агент → поле «API-ключ» → «Сохранить и проверить»**.
   Кнопка делает реальный тестовый запрос (`ping`): ключ сохраняется только если провайдер его принял.
3. Ключ хранится **только в вашем браузере** (localStorage) и передаётся вашей же функции на Netlify
   с каждым запросом (`clientKey`). Кнопка «Удалить ключ» стирает его с подтверждением.

## Как включить — способ 2: переменные окружения Netlify (для команды)

1. Получите **любой** из ключей:
   - платный: [console.anthropic.com](https://console.anthropic.com/) → API Keys → `ANTHROPIC_API_KEY`;
   - **бесплатный**: [aistudio.google.com](https://aistudio.google.com/) → «Get API key» → `GEMINI_API_KEY`;
   - **бесплатный**: [openrouter.ai](https://openrouter.ai/) → Keys → `OPENROUTER_API_KEY`.
2. Netlify → ваш сайт → **Site configuration → Environment variables** → добавьте переменную с ключом.
3. **Deploys → Trigger deploy → Deploy site.**
4. Проверка: Настройки завода → блок «ИИ-агент» должен показать «Агент активен» с именем провайдера и модели.

Серверные env-ключи имеют приоритет над ключом из браузера.

Стоимость: Gemini/OpenRouter — бесплатные лимиты (хватает на сотни распознаваний в день);
Claude Opus 4.8 — платно, распознавание одного фото ≈ $0.02–0.05, зато лучшее чтение постов и сайтов.

## «А можно агента через гит?» — можно, вот честный расклад

Фреймворки для Claude Code существуют, и «агент через git» — реальный паттерн:

- **[claude-code-action](https://github.com/anthropics/claude-code-action)** — GitHub Action,
  запускающий Claude Code прямо в CI. Может анализировать файлы в репозитории,
  коммитить результаты, отвечать на issue. Работает и по API-ключу, и по
  **OAuth-токену подписки Claude Pro/Max** (`CLAUDE_CODE_OAUTH_TOKEN` в секретах —
  `claude setup-token` локально), то есть без пометочной оплаты API.
- **Claude Agent SDK** — фреймворк для собственных агентов (Node/Python) поверх
  Claude Code; подходит для серверного бэкенда, но это уже отдельный сервис.

**Почему для этого дашборда основной путь — serverless, а не Action:**
git-агент асинхронный (минуты: коммит → CI → результат → пулл), а распознавание
товара нужно за секунды прямо при загрузке фото. Секрет (ключ или OAuth-токен)
нужен в обоих вариантах; разница лишь в том, где лежит секрет
(Netlify env vs GitHub Secrets) и какая задержка. Если платить не хочется —
используйте бесплатные ключи Gemini или OpenRouter из таблицы выше.

**Где git-агент уместен и что можно добавить по запросу:** ночной батч-разбор
всех новых скринов/фото очередью, авто-обновление базы знаний типов товаров,
еженедельный отчёт по контенту — such задачи не требуют мгновенного ответа,
и для них подключу `claude-code-action` с вашим OAuth-токеном подписки.

## Privacy

Фото товаров и скрины постов уходят только в API выбранного вами провайдера
(Anthropic / Google / OpenRouter) по вашему ключу. Учтите: у бесплатных тарифов
Google и OpenRouter данные могут использоваться для улучшения моделей — для
коммерческих фото это обычно не проблема, но знать стоит. Токены и ключи
в репозитории не хранятся.
