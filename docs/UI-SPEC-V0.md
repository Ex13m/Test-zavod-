# UI-спецификация «Контент-Завод» — задание для v0

> Готовый бриф: скопируйте целиком (или по разделам) в v0.dev как задание.
> Описывает весь интерфейс дашборда версии 0.11.0 — экраны, компоненты,
> дизайн-токены, анимации, состояния, мобильное поведение.

---

## 1. Что это за продукт

**«Контент-Завод» (Lure Content Factory)** — одностраничный дашборд (SPA) на русском языке
для владельца рыболовного магазина. Метафора интерфейса — **завод/фабрика**: пользователь
загружает фото товара (приманка, крючки, удочка…), «конвейер» собирает продающий пост-воронку
(hook → выгоды → доказательство → CTA со ссылкой на сайт + UTM), пост попадает на «склад»
(история) и «раздаётся по цехам дистрибуции» (Telegram, вебхук автопостинга, соцсети).

Технологии оригинала: React 18 + Vite, Zustand (persist в localStorage), изображения в
IndexedDB. Бэкенда нет — всё в браузере + 2 serverless-функции (Telegram-прокси, ИИ-агент).

## 2. Дизайн-концепция: «Янтарная глубина»

Тёмная кинематографичная подводная сцена. Ощущение: ночная рыбалка, толща тёмной воды,
единственный тёплый источник света — светящаяся янтарная приманка. Интерфейс — «стеклянные»
панели, плавающие над живым подводным фоном.

**Запрещено:** эмодзи в интерфейсе (только в текстах сгенерированных постов), леденцовые
градиенты, фиолетово-неоновый «AI-стиль», стоковые иллюстрации людей.

### 2.1 Палитра (CSS-переменные)

```css
--bg: #060a12;            /* почти чёрная вода */
--bg-2: #0a1220;          /* глубина 2 */
--panel: rgba(15,23,39,0.30);   /* стекло панелей — 70% прозрачности! */
--stroke: rgba(148,180,208,0.14);      /* обводки */
--stroke-bright: rgba(148,180,208,0.30);
--ink: #e8f0f8;           /* основной текст */
--ink-dim: #9fb4c8;       /* вторичный */
--ink-faint: #5f7690;     /* подписи */
--acc: #ffb454;           /* ЯНТАРЬ — главный акцент (свет приманки) */
--acc-2: #7fd0ff;         /* ледяная вода — второй акцент */
--ok: #55d187;            /* успех */
--danger: #fb7185;        /* опасность */
```

Фирменный градиент иконок: линейный `#eaf2fa → #ffb454` (сверху-слева вниз-вправо),
применяется как stroke ко всем ключевым иконкам + мягкое свечение
`drop-shadow(0 0 6px rgba(255,180,84,0.35))`.

### 2.2 Типографика

- Заголовки/акциденция: **Tektur** (Google Fonts) — трафаретный технический гротеск,
  верхний регистр, letter-spacing 0.04–0.08em.
- Текст: **IBM Plex Sans**. Моно (журналы, метки версий): **IBM Plex Mono**.
- Заголовок экрана: 26–30px, часть слова выделена янтарным (`<span class="glow">`)
  с лёгким свечением. Подпись под заголовком: 14px, --ink-dim.
- Заголовки панелей: 11px, uppercase, letter-spacing 0.14em, с иконкой 14px слева
  и тонкой линией-протяжкой справа.

### 2.3 Панели-«стекло»

- Фон `var(--panel)` (70% прозрачности), `backdrop-filter: blur(14px)`,
  радиус 16px, обводка 1px `var(--stroke)`, внутренний отступ 18–20px.
- При hover карточки приподнимаются `translateY(-2px)`, обводка ярчает.

## 3. Живой фон (за всем интерфейсом, aria-hidden)

Слои снизу вверх:

1. **Фото-фон**: тёмное подводное фото (лучи света сверху), затемнено градиентами
   сверху и снизу; если фото нет — радиальные градиенты глубины.
2. **Волновые полосы** (как флаги глубин): 4 горизонтальные SVG-синусоиды цвета
   `#8fb2d0` на 30/48/64/78% высоты, opacity 0.05–0.12, каждая медленно дрейфует
   по горизонтали (translateX 0→−50%, длительности 46/38/30/24s, ширина svg 200%).
3. **Пять параллакс-слоёв рыб и водорослей** (от глубины к поверхности:
   abyss / far / mid / near / front — 17 рыб, масштабы 0.3–1.6, проплыв
   30–140s, оба направления):
   - Рыбы — **монолитные силуэты** без фона, 5 видов: щука (стрела с утиным носом),
     судак, окунь (горбатый), жерех, форель. Основной источник — прозрачные
     PNG-стикеры Higgsfield (Recraft V4.1 → background remover, реестр `src/art.js`);
     фолбэк — встроенные SVG (сплошная заливка currentColor, БЕЗ контуров и деталей).
   - Дальний слой: blur 2px, opacity 0.12, цвет #a8c4dc, масштаб 0.4–0.55, проплывают
     за 95–120s. Средний: blur 0.8px, opacity 0.16, #94b4d0, масштаб 0.7–0.85, 58–74s.
     Ближний: без blur, opacity 0.22, #7fa2c2, масштаб 1.15–1.45, 38–46s.
   - Рыбы плывут по горизонтали через весь экран (часть слева-направо, часть справа-налево,
     отражённые), плюс лёгкое вертикальное покачивание (6–11s).
   - Водоросли: пучки из 2–3 листьев (SVG-лепестки), закреплены к низу, качаются
     rotate ±4° (7–11s), высоты 70–240px.
4. **Рыба-охотник** (canvas, поверх слоёв, под панелями): анимированная рыба из
   22 сегментов позвоночника (инверсная кинематика) гонится за блуждающей светящейся
   янтарной приманкой-точкой. Приманка оставляет мягкое свечение и пузырьки. Рыба
   серебристо-голубая, полупрозрачная, спинной гребень всегда на спине, хвост с вилкой.
5. Лёгкая «аврора» — едва заметное цветовое пятно, медленно плывущее по экрану.

`prefers-reduced-motion: reduce` — все анимации выключаются.

## 4. Каркас приложения

- **Сайдбар слева** (фикс. ширина ~230px): логотип (стилизованная рыба в рамке 44px +
  «КОНТЕНТ-ЗАВОД» / «lure factory»), переключатель воркспейса-магазина (select +
  кнопка «+», либо кнопка «+ Магазин по сайту», если магазинов нет), 7 пунктов навигации
  с иконками: Пульт, Товары (бейдж-счётчик), Конвейер, Стиль, История (бейдж), Дистрибуция,
  Настройки. Активный пункт — стеклянная плашка с янтарной полоской слева и градиентной
  иконкой. Внизу — примечание «v0.11.0 · посты и фото хранятся локально в вашем браузере».
- **Бейдж версии** в правом верхнем углу: `◇ v0.11.0 · 05.07.2026` — кликабелен,
  открывает окно «Что нового».
- **Основная область**: заголовок экрана + подзаголовок, затем контент.
  Типовая сетка: `grid-main` = 380px (левая колонка настроек) + 1fr (результат),
  либо `grid-2` = 1fr 1fr. На мобильном всё в одну колонку.
- **Тосты** — снизу по центру, стеклянные, с градиентной иконкой, автоскрытие 3.2s.

## 5. Экраны

### 5.1 Пульт (дашборд)

- 4 стат-плитки: «Товаров на складе», «Постов произведено», «Отправлено в каналы»,
  «Скринов стиля изучено». Крупная цифра 28–32px Tektur, подпись uppercase 10px,
  градиентная иконка. У плиток тонкая янтарная верхняя кромка.
- Панель «Технологическая цепочка»: 4 шага-карточки (1. Загрузите фото товара →
  2. Соберите пост на конвейере → 3. Скопируйте стиль со скринов → 4. Разошлите по
  каналам), каждый с иконкой, описанием и стрелкой; клик ведёт на соответствующий экран.
- Панель «Последние посты»: мини-список последних 3 постов (фото 52px, заголовок, дата).

### 5.2 Товары (склад)

- Баннер статуса ИИ-агента: зелёный «ИИ-агент активен: тип, бренд и название
  определяются по самому фото» ЛИБО нейтральный кликабельный «ИИ-агент не подключён —
  тип угадывается по имени файла. Нажмите: инструкция по включению, есть бесплатные
  варианты» → ведёт в Настройки.
- Дроп-зона на всю ширину: пунктирная рамка, градиентная иконка фотоаппарата,
  «Перетащите фото товаров или нажмите» — приём нескольких файлов.
- Сетка карточек товаров (auto-fill, minmax 210px): фото 150px cover, тип-тег
  (янтарный chip: «Воблер», «Крючки», «Удилище»…), название, бренд-тег, дата,
  кнопки «На конвейер» и удалить. После загрузки тип/название определяются автоматически
  (ИИ по фото или эвристика по имени файла) — селекта типа НЕТ.

### 5.3 Конвейер (генерация)

Левая колонка «Рецептура поста»:
- Блок «Товар — определён автоматически»: тег типа + название + бренд + кнопка «Сменить»
  (ведёт на склад). Ниже фото товара (150px).
- Чипы «Формула воронки»: AIDA / PAS / Сторителлинг / Экспертный разбор / FOMO
  (+ описание выбранной под чипами).
- Чипы «Тон»: Дружеский / Экспертный / Продающий-дерзкий / Спокойный премиум.
- Чипы «Длина»: Короткий / Средний / Длинный.
- Чипы «Язык поста»: RU · Русский / EN · English / CS · Čeština.
- Если изучены скрины: плашка «Стиль скопирован с N скринов».
- Большая янтарная кнопка «Запустить конвейер».

Правая колонка:
- Панель «Линия сборки»: 6 этапов конвейера в ряд (Приёмка фото → Анализ приманки →
  Профиль стиля → Копирайт-цех → Сборка воронки → Выпуск). Каждый — квадратная ячейка
  с иконкой; активный подсвечен янтарным и пульсирует, пройденный — зелёная галочка,
  между ячейками анимированные линии-«потоки». Этапы сменяются каждые ~320ms.
- Панель «Готовый пост»: пустое состояние с иконкой и текстом «Пресс-формы чистые…»;
  при генерации текст ПЕЧАТАЕТСЯ посимвольно с мигающим кареткой-курсором; ниже
  мета-теги (формула, тон, язык, число символов) и кнопки: «Сохранить в историю»
  (первичная), «Копировать», «Пересобрать», после сохранения — «К дистрибуции →».
- При сохранении срабатывает **автопостинг**: пост сам уходит в каналы, где включены
  оба тумблера «канал»+«авто»; тост показывает итог.

### 5.4 Стиль (копирование манеры)

- Дроп-зона для скриншотов постов магазина.
- Сетка загруженных скринов (миниатюры с удалением).
- Панель «Профиль стиля»: после анализа — строки-характеристики (язык, тон,
  плотность эмодзи, длина, рубленость, формальность, hashtags-чипы, фирменные
  обороты, CTA-манера) с прогресс-полосками 0–1 там, где уместно; кнопка
  «Изучить стиль заново». Профиль влияет на генератор.

### 5.5 История (склад продукции)

- Список постов: строка-карточка = фото 84px, заголовок + первые строки текста,
  теги (формула/тон/язык/каналы, куда опубликован), дата; действия: «Копировать
  текст», «В дистрибуцию», удалить. Фильтр по активному магазину-воркспейсу.

### 5.6 Дистрибуция

- Левая панель «Каналы» — 7 карточек: Telegram (реальный, «Bot API через Netlify
  Function»), Автопостинг-вебхук (реальный, «n8n · Make · Zapier · Albato»),
  Facebook*, ВКонтакте, Дзен, Instagram*, Одноклассники (заглушки с тегом «скоро»).
  У КАЖДОЙ карточки справа **два мини-тумблера в столбик**: «КАНАЛ» (участвует в
  ручной рассылке) и «АВТО» (пост уходит сам при выпуске с конвейера; недоступен,
  пока не включён «канал» — тогда полупрозрачен). Подпись-легенда под списком +
  сноска про Meta.
- Правая колонка: панель «Telegram» (поля «Токен бота», «ID канала/чата», подсказки,
  «Токен хранится только в вашем браузере»); панель «Автопостинг» (чипы сервиса
  n8n/Make/Zapier/Albato/Свой URL, поле URL вебхука, тумблер «Прикладывать фото»);
  панель «Отправка»: select поста со склада, превью текста, янтарная кнопка
  «Разослать по включённым каналам», ниже — моноширинный журнал строк
  («Telegram → OK, опубликовано», «Вебхук → ошибка: …»).

### 5.7 Настройки

- Панель «Воронка и трафик»: бренд, сайт для CTA, тумблер UTM + utm_source.
- Панель «Рецептура по умолчанию»: те же чипы формулы/тона/длины/языка.
- Панель «ИИ-агент»: статус — зелёная плашка «Агент активен · провайдер · модель»
  ЛИБО инструкция подключения с тремя вариантами ключей (бесплатные GEMINI_API_KEY /
  OPENROUTER_API_KEY, платный ANTHROPIC_API_KEY — минимум Opus 4.8).
- «Опасная зона»: красная кнопка «Полный сброс завода» с confirm.

### 5.8 Онбординг (первый запуск, поверх всего)

Мастер из шагов на стеклянной карточке по центру, фон затемнён:
1. Приветствие + «Пропустить» (тогда сеется демо-контент).
2. Ввод адреса сайта магазина («вводишь адрес — все настройки под него»).
3. Анимация сканирования сайта (строки-«лучи» с прогрессом).
4. Профиль магазина: имя, язык, ниша, бренды, аудитория, теги — можно поправить.
5. Посев демо: товар + скрины постов + 2 готовых поста.
6. Готово → в дашборд. Повторный запуск — кнопкой «+ магазин» (мульти-воркспейсы).

### 5.9 Виртуальный помощник «Капитан Окунь»

- Плавающая кнопка справа-снизу: рисованный персонаж-окунь (морская фуражка,
  янтарные плавники), парит вверх-вниз.
- Пузырь подсказки: заголовок «КАПИТАН ОКУНЬ» + тег «ШТУРМАН», контекстный совет
  в зависимости от экрана и состояния данных, кнопки «Инструкция и PDF» и «Свернуть».
- Модал «Инструкция»: быстрый старт по шагам, ссылки на скачивание 2 PDF
  (настройка n8n+Telegram; Make/Zapier автопостинг), история версий.

### 5.10 «Что нового» (анонс версии)

При первом заходе на новую версию — красивая карточка сверху по центру:
градиентная рамка, «◇ Обновление v0.11.0», заголовок релиза, 3–4 пункта списком,
прогресс-полоска времени; плавное появление, висит 15 секунд, плавное исчезание.
Закрывается кликом; повторно — по клику на бейдж версии.

## 6. Мобильная версия (≤700px)

- Сайдбар сжимается до колонки иконок (~64px); кнопка магазина — компактный «+».
- Все сетки в одну колонку; стат-плитки 2×2; конвейер переносится (ячейки по 30%).
- Помощник 58px, пузырь ≤78vw. Бейдж версии мельче. Отступы 12–16px.
- Grid-дети с `min-width: 0` — длинный контент не распирает экран, горизонтального
  скролла нет нигде.

---

## 7. Иконография

Единый набор stroke-иконок 1.6px (без эмодзи): рыба-лого, фотоаппарат, линза,
веер-стиль, перо, воронка, куб, шестерня, вышка-передатчик, бумажный самолётик,
звено-цепь, галочка, копия, корзина, домик-пульт, крючок-товары, конвейер, соцсети
(fb — круг с f, vk, дзен-спираль, instagram-квадрат, ok). Ключевые — с фирменным
градиентом «янтарь→лёд» и мягким свечением.

---

## 8. Микро-анимации

- Кнопки: hover — приподнимание 1px + усиление свечения; primary — янтарный градиент.
- Чипы: переключение цветом и обводкой, лёгкий scale.
- Конвейер: пульс активной ячейки, «бегущий поток» на связях.
- Печать текста поста: 2–6 символов за тик 12ms, каретка мигает.
- Тумблеры: пружинный сдвиг шайбы (cubic-bezier spring), включённый — янтарный градиент.
- Появление панелей при смене экрана: fade + подъём 8px, stagger 40ms.
