# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),

## [0.2.0] — 2026-07-05

### Добавлено
- **Фирменный стиль «Зигфелд» (ар-деко):** единый набор из 30+ SVG-иконок ручной
  работы (тонкий штрих 1.5px, веера, лучи, ступени) вместо эмодзи — навигация,
  статистика, конвейер, каналы, действия, пустые состояния.
- Фирменный знак — геометрическая рыба-ар-деко с градиентом бирюза→золото.
- Ар-деко орнаментика: двойные золотые рамки панелей, солнце-веер за заголовками,
  двухслойная золотая линия под названием раздела.

### Изменено
- Иконки навигации подсвечиваются золотом в активном состоянии.

### Исправлено
- Согласование рода в шаблонах генератора («этот воблер» / «эта вертушка»).
- Кириллический домен в CTA-ссылке больше не превращается в punycode.
- Журнал дистрибуции: убраны «сырые» идентификаторы иконок из строк лога.

## [0.1.0] — 2026-07-05

### Добавлено
- **Дашборд «Пульт»**: статистика склада/выпусков, технологическая цепочка, последние посты.
- **Склад приманок**: drag&drop загрузка фото, сжатие до 1200px, автоопределение типа
  по имени файла (8 типов приманок), правка типа на карточке.
- **Конвейер генерации**: 5 формул воронки (AIDA, PAS, Сторителлинг, Экспертный разбор,
  FOMO) × 4 тона × 3 длины; база знаний по каждому типу приманки (рыба, сезоны, выгоды,
  боли, соцдоказательства, лексика); детерминированный PRNG для пересборки; UTM-разметка
  CTA-ссылок; анимация линии сборки и печатающийся текст.
- **Копирование стиля**: загрузка скринов эталонных постов, эвристический анализ v1
  (яркость/насыщенность/плотность текста) → профиль повествования, влияющий на генерацию.
- **История**: склад готовой продукции с фильтрами, копированием, экспортом JSON,
  отметками публикации.
- **Дистрибуция**: Telegram через serverless-прокси (Netlify Function `telegram-post`),
  универсальный вебхук автопостинга (пресеты n8n/Make/Zapier/Albato), заглушки ВК/Дзен/
  Instagram/ОК, журнал отправки.
- **Настройки**: бренд, сайт воронки, UTM, рецептура по умолчанию, полный сброс.
- **Анимация**: canvas-сцена — процедурная рыба (22-сегментный позвоночник, IK)
  преследует блуждающую приманку, пузырьки, планктон, лучи света; аврора-градиент;
  поддержка prefers-reduced-motion.
- **Документация**: SPEC.md (по методике spec-pilot), ROADMAP.md, README.md, CHANGELOG.md.

### Исправлено (в ходе self-verify)
- Согласование рода в шаблонах («этот воблер» / «эта вертушка»).
- Кириллические домены в CTA больше не превращаются в punycode.
